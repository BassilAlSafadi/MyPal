# Operational Playbooks & Runbooks Summary

Welcome to the MyPal Operational Playbooks.

This directory contains standardized recovery procedures, incident response templates, and operational runbooks for maintaining the MyPal distributed architecture.

## Structure
* `/docs/runbooks/` - Specific component recovery (Sagas, DLQ, Outbox).
* `/docs/failure-scenarios/` - Architectural failure planning.
* `/docs/recovery-procedures/` - Infrastructure recovery (DB failovers).
* `/docs/observability/` - Tracing and metrics guidelines.
* `/docs/deployment/` - Deployment configurations.
* `/docs/operations/` - Standard checklists and incident handling.

**Note to AI Agents**: Always consult these runbooks before suggesting infrastructural modifications to ensure constraints are respected.
